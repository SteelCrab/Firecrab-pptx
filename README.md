# Firecrab-pptx

Firecrab의 대회 발표자료를 관리한다. 편집 기준은 이 폴더의 최신 제출본이다.

## 최신 자료

`latest`는 `output/Firecrab_3633_제출자료`를 가리킨다.

- `latest/제출파일`: 발표 PPTX, PDF와 참가팀 정보 확인서 XLSX를 보관한다.
- `latest/발표준비`: 발표 대사 PDF·Markdown, 페이지별 설명과 90초 촬영 대본을 보관한다.
- `latest/이미지/슬라이드`: 1920×1080 슬라이드 PNG 17장을 보관한다.
- `latest/이미지/원본`: 발표자료에 사용한 원본 이미지 24개를 보관한다.
- `latest/참고자료`: 공지와 발표자료 구성 기준 이미지를 보관한다.

발표자료의 파일명은 `2026 오픈소스 개발자대회 2차 평가 발표 자료_3633_JustForFun`이다.
PPTX를 편집 원본으로 사용한다. PDF와 PNG는 같은 PPTX에서 내보낸다.

## 발표 구성

제목 → 팀 소개 → 프로젝트 개요 → 개발 배경과 목적 → 프로젝트 구성과 기능 → 기능 시연 → 활용 방안과 계획 → 마무리

본편은 15장이다. 질의응답용 부록은 2장이다. 발표 목표는 시연 90초를 포함한 10분이다.
팀은 JustForFun이다. 발표자는 박용현이다. 접수번호는 3633이다.

웹 콘솔은 React, 터미널은 Ghostty Web으로 설명한다.
AI Canvas는 협업 AI 작업 공간이며 AI 기능 중 하나다.

## 편집 방법

1. `latest/제출파일`의 PPTX를 수정한다.
2. 같은 이름의 PDF와 슬라이드 PNG를 갱신한다.
3. 발표 대사와 페이지별 설명을 새 페이지 번호에 맞춘다.
4. 이미지 목록과 원본 이미지의 사용 페이지를 갱신한다.
5. 변경 내용을 확인한 뒤 Git에 기록한다.

완성 자료의 압축파일은 `output/Firecrab_3633_자료_전체.zip`이다.
이미지 압축파일은 `output/Firecrab_3633_이미지_모음.zip`이다.
압축파일은 배포용 산출물이다. 수정 후 최신 제출본에서 다시 만든다.

## 관리 범위

Git은 최신 제출자료와 이 관리 문서를 추적한다.
이전 시안과 생성 작업 기록, 캐시와 압축파일은 로컬에 보관한다.
과거 생성 기록은 `.build`에 있다. 각 기록은 당시 입력 파일을 기준으로 만든다.
새 편집은 최신 PPTX를 먼저 확인한 뒤 진행한다.

이전 작업 경로인 `/Users/pista/firecrab-projects/presentation-artifacts/firecrab-contest-20261030`은 이 폴더로 연결한다.
기존 파일 경로에서도 최신 제출본을 열 수 있다.

## 제출 전 입력

참가팀 정보 확인서의 연락처는 D34에 입력한다.
재촬영한 영상의 YouTube 주소는 C28에 입력한다.
