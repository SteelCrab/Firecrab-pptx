# Firecrab 90초 시연 영상 촬영 대본

현재 상태는 재촬영 대기다. 영상 주소는 촬영과 업로드를 마친 뒤 입력한다.
영상은 16:9, 1920×1080으로 준비한다. 90초 영상 재생은 발표 10분에 포함한다.

## 촬영 준비

AI 작업 결과와 배포할 OCI 이미지를 미리 준비한다. 실제 실행 결과와 앱 화면을 사용한다.
브라우저 글자를 읽을 수 있는 크기로 확대한다. 학교·회사 정보와 접속 자격증명 입력 화면을 촬영에서 제외한다.

| 구간 | 화면 | 대사 |
| --- | --- | --- |
| 00-20초 | AI Sandbox의 변경 파일, 명령과 테스트 결과 | 먼저 AI 작업 결과다. 변경 파일과 실행한 명령, 테스트 결과를 확인한다. 검토 후 원본에 반영할 파일을 선택한다. |
| 20-40초 | 연결된 MicroVM의 상태, 할당 자원과 콘솔 | 이 작업에 연결된 MicroVM이다. 실행 환경과 할당 자원, 콘솔을 확인한다. |
| 40-70초 | 준비한 이미지로 Deploy 실행, 준비 상태 확인 | 검토한 코드로 미리 준비한 이미지를 배포한다. 배포 요청 후 앱 준비 상태와 실행 상태를 확인한다. |
| 70-90초 | 앱 접속, 배포 상태와 로그 | 배포한 앱에 접속하고 로그와 이벤트를 확인한다. AI 작업 검토부터 앱 운영 확인까지 이어지는 과정이다. |

## 촬영 후 반영

현장 재생용 MP4 파일을 발표 자료와 함께 USB에 보관한다.
YouTube 공개 범위는 공개 또는 일부 공개로 설정한다.
새 영상 주소를 참가팀 정보 확인서의 C28에 입력한다. 기존 영상 주소로 채우지 않는다.
