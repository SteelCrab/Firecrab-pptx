# Firecrab 제출자료

팀은 JustForFun이다. 발표자는 박용현이다. 접수번호는 3633이며 참가부문은 일반이다.
본편은 15장, 질의응답용 부록은 2장이다. 발표 목표는 시연 90초를 포함한 10분이다.

## 발표 흐름

제목 → 팀 소개 → 프로젝트 개요 → 개발 배경과 목적 → 프로젝트 구성과 기능 → 기능 시연 → 활용 방안과 계획 → 마무리

## 제출파일

제출파일 폴더의 PPTX, PDF와 참가팀 정보 확인서 XLSX를 제출한다.
PPTX와 PDF는 같은 17페이지 구성이다. 16~17페이지는 질의응답용 부록이다.
업로드는 2차 평가 안내 메일의 Dropbox 링크에서 진행한다.
공지의 제출 기한은 2026년 11월 1일 23:59다.

## 추가 입력

참가팀 정보 확인서의 D34에 평가장 입장 연락처를 입력한다.
영상은 재촬영한다. 새 YouTube 주소를 C28에 입력한다.

## 이미지와 발표 준비

이미지/슬라이드에는 1920×1080 PNG 17장을 보관한다.
이미지/원본에는 발표자료에서 사용한 원본 이미지 28개를 보관한다.
AI Canvas 원본은 자르거나 크기를 바꾸지 않았다.
발표준비 폴더에는 발표 대사 PDF와 Markdown, 페이지별 설명과 90초 촬영 대본을 보관한다.
참고자료 폴더에는 공지 이미지와 발표자료 구성 기준 이미지를 보관한다.
